## Highlights
\- Autonomous APRILTag-based movement and positioning code. Unfortunately, the club has since set the Github to private. Thanks to {{<targetblank href="https://github.com/sfe-SparkFro">}} Dryw Wade {{</targetblank>}} for providing a great example OpMode to work off of.
